## ⚠️ 가이드 위반 사항

### 1. 이모지 과다 사용

**CLAUDE.md 규칙:**
> **이모지 사용 자제**: 기본적으로 사용하지 않음

**실제:**
- ✅ (30회 이상)
- 📱, 🔔, 📎, 💬, 🎉, 🎯
- 📰, ✍️, 📋, 🤖
- 📚, 🔧, 👥, 💻, 💬

**권장:**
- 기술 블로그에서는 이모지 제거
- 필요하면 섹션 구분용으로만 (최소화)

**수정 예시:**
```markdown
# ❌ 현재
**장점:**
- 📱 모바일에서 사용 가능
- 🔔 알림 받기

# ✅ 권장
**장점:**
- 모바일에서 사용 가능
- 알림 받기
```

### 2. AI 티는 아니지만 친근한 톤

**CLAUDE.md 규칙:**
> **회사 기술 블로그 스타일**: Netflix Tech Blog, Uber Engineering 수준

**실제:**
- "~할 수 있다" (여러 번)
- "당신의", "당신만의"
- "오늘 시작해보자"

**평가:**
- "~해볼까요?" 같은 AI 티는 아님
- 하지만 Netflix/Uber 스타일보다는 친근함

**이 글의 특성상 괜찮음:**
- 대상: 비개발자 포함
- 목적: 제품 소개 + 튜토리얼
- 친근한 톤이 오히려 접근성 높임

**하지만 기술 분석 글에서는:**
```markdown
# ❌ 친근한 톤
Clawdbot은 당신만의 AI 비서, 오늘 시작해보자.

# ✅ 전문적 톤
Clawdbot은 개인 맞춤형 AI 어시스턴트 플랫폼이다.
```

### 3. 너무 긴 트러블슈팅 섹션

**문제:**
- Discord 설정 트러블슈팅이 너무 상세함
- 케이스별로 나눠서 복잡함

**권장:**
- 핵심만 남기고 공식 문서 링크
- 이미 간소화했지만 더 줄일 수 있음

**현재:**
```markdown
**트러블슈팅:**

**응답이 없는 경우:**
1. `clawdbot status`로 상태 확인
2. `clawdbot logs --follow`로 로그 확인
3. Discord Developer Portal에서 Intents 확인
4. `dm.allowFrom`에 자신의 ID 추가 확인
```

→ ✅ 이미 간결함. 괜찮음.
