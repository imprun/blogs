# Claude Code 12월 사용 리포트: 23억 토큰의 한 달

> **작성일**: 2025년 12월 30일
> **카테고리**: AI, Developer Tools, Usage Analysis
> **키워드**: Claude Code, Claude Max, AI Coding Assistant, Token Usage, Monthly Report

## 요약

2025년 12월 한 달간 Claude Code로 23억 토큰을 사용했다. API 환산 비용 $1,844, 일평균 $74 수준이다. 11월 측정 가능 기간(15~30일) 대비 일평균 사용량이 12배 증가했으며, 캐시 적중률 94%를 유지했다.

## 측정 환경

- **구독 플랜**: Claude Max 20 ($200/월)
- **측정 기간**: 2025년 12월 1일 ~ 12월 31일
- **측정 도구**: [ccusage](https://github.com/ryoppippi/ccusage)
- **활동일**: 25일 (12/1, 12/2, 12/13, 12/20, 12/24~26 제외)
- **주요 작업**: imprun-apigateway v3 개발, 기술 블로그 작성

## 11월 대비 변화

이전 리포트([12억 토큰 리포트](https://blog.imprun.dev/81))에서 11월 15일~12월 11일 데이터를 분석했다. 단, 11월은 로그 삭제로 15~30일(7일)만 데이터가 존재하므로, 총량이 아닌 **일평균**으로 비교해야 공정하다.

| 기간 | 활동일 | 총 토큰 | 일평균 토큰 | 일평균 비용 |
|------|--------|---------|------------|------------|
| 11월 (15~30일) | 7일 | 52.7M | 7.5M | $3.64 |
| 12월 1~11일 | 11일 | 1.21B | 110M | $84.23 |
| **12월 전체** | **25일** | **2.3B** | **92M** | **$73.76** |

일평균 기준 11월 대비 12월:
- **일평균 토큰**: 7.5M → 92M (**12배 증가**)
- **일평균 비용**: $3.64 → $73.76 (**20배 증가**)

11월은 데이터 측정 기간이 짧아(7일) 직접 비교에 한계가 있다. 12월에는 v3 개발과 블로그 작성 작업량이 증가했다.

## 캐싱 효율 분석

### 캐싱이 없었다면?

12월 총 토큰 2.3B를 캐싱 없이 모두 Opus Input으로 처리했다면:

| 시나리오 | 계산 | 비용 |
|----------|------|------|
| 캐싱 적용 (실제) | ccusage 측정값 | **$1,844** |
| 캐싱 미적용 (가정) | 2.3B × $5/1M | **$11,500** |

캐싱으로 약 **84%** 비용 절감 효과를 얻었다. 물론 Max 구독자는 월 $200 고정이므로 실제 지불액과는 무관하지만, 사용량 규모를 가늠하는 지표로 활용할 수 있다.

## 결론

12월 한 달간 23억 토큰, API 환산 $1,844를 사용했다. 11월 측정 기간(15~30일) 대비 일평균 사용량이 12배 증가했다.

Max 구독 $200/월로 API 환산 $1,844 상당의 작업을 수행했다. 프롬프트 캐싱의 94% 적중률이 비용 효율을 유지하는 핵심 요인이다.
